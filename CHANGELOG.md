### 2026-09-08 — убраны Google Таблицы

#### Removed

- Папка `apps-script/` и весь поток через Google Таблицы: листы «Настройки» / «Данные», боковая панель, меню таблицы.

#### Changed

- Репозиторий описывает только веб-сервис в `server/`.

### 2026-09-07 — локальный сервис для ассистентов АМ

#### Added

- В папке `server/` — локальный веб-сервис: форма всех полей ввода, экран прогресса сбора из Метрики, скачивание self-contained HTML. Хранилище — SQLite (`data/reports.sqlite`), `window.REPORT` в файле отчёта нет.
- Запуск: `cd server`, `npm install`, `npm start`, затем `http://localhost:3000`. Интернет нужен только для API Метрики.
