# Отчёт Яндекс.Метрики для ассистентов АМ

Локальный веб-сервис: форма всех полей ввода, сбор цифр из API Метрики, скачивание HTML-отчёта. Google Таблиц нет.

Ассистент открывает браузер на `http://localhost:3000`, заполняет настройки и медиаплан, нажимает «Собрать отчёт», ждёт прогресс и скачивает файл. Шаблон слайдов на диске не перезаписывается: цифры подставляются на сервере в копию.

## Запуск

```bash
cd server
npm install
npm start
```

Откройте [http://localhost:3000](http://localhost:3000). Интернет нужен только для API Метрики.

Токен в репозиторий не входит: его вставляют в форму. База SQLite — `data/reports.sqlite`, в git не попадает.

## Что попадает в отчёт

Из Метрики (срез программатик = `utm_source`, при метке ещё «другие источники»):

- клики как визиты, глубина, отказы, среднее время;
- устройства, возраст (включая «не определено»), пол;
- поведение в разрезе возраста и пола;
- топ-10 городов по выбранным post-click целям;
- доля новых пользователей;
- прямые и ассоциированные конверсии, итог PC;
- клики по `utm_content` (баннеры).

План медиаплана, бюджет, CTR, частота, post-view и контакты вводятся руками на форме.

Что API может отдать иначе, чем кабинет — в [docs/metrika-risks.md](docs/metrika-risks.md).

## OAuth-токен Метрики

Нужно право `metrika:read`.

1. Создайте приложение на [oauth.yandex.ru](https://oauth.yandex.ru) с доступом «Получение статистики, чтение параметров своих и доверенных счётчиков».
2. Откройте в браузере:

   `https://oauth.yandex.ru/authorize?response_type=token&client_id=ИД_ПРИЛОЖЕНИЯ`

3. Скопируйте `token` из адресной строки и вставьте в форму сервиса.

## Структура

```
server/
  index.js           страница формы, прогресс, скачивание HTML
  collect.js         шаги сбора и запись в SQLite
  metrika.js         запросы к API Яндекс.Метрики
  fields.js          поля формы
  db.js              SQLite (sql.js)
  fill-template.js   подстановка цифр в шаблон без window.REPORT
  public/            стили и экран прогресса
report/
  index.html         макет слайдов
  styles.css
docs/
  metrika-risks.md   где цифры Метрики могут не совпасть с кабинетом
```
