# Отчёт Яндекс.Метрики для Google Таблиц

Скрипт Google Apps Script, который собирает в таблицу готовый отчёт по счётчику Яндекс.Метрики: визиты и поведение, возраст, пол, устройства и выбранные цели.

Предназначен для аккаунт-менеджеров: заполняете лист «Настройки», нажимаете «Собрать отчёт» — цифры появляются на листе «Данные».

## Что попадает в отчёт

- клики (визиты), глубина просмотра, отказы, среднее время на сайте;
- при указанной метке `utm_source` — те же поведенческие показатели по всем остальным источникам;
- распределение по возрасту, полу и устройствам;
- конверсии по выбранным целям Метрики (прямые и, если задана метка, ассоциированные).

Токен Метрики в репозиторий не входит: его вставляют в таблицу один раз, скрипт сохраняет его в свойствах документа и скрывает ячейку.

## Установка

1. Откройте Google-таблицу → **Расширения** → **Apps Script**.
2. Удалите содержимое стандартного `Code.gs` и создайте файлы:
   - `Code.gs`
   - `Metrika.gs`
   - `Sheets.gs`
   - `Sidebar.html`
   - `appsscript.json`
3. Скопируйте в них содержимое из папки [`apps-script`](apps-script) этого репозитория.
4. Сохраните проект (`Ctrl+S`) и обновите таблицу — появится меню **Отчёт Метрики**.
5. Меню **Подготовить таблицу**, затем заполните жёлтые поля: номер счётчика, OAuth-токен, период. Метка и конверсии необязательны.

## OAuth-токен Метрики

Нужно право `metrika:read`.

1. Создайте приложение на [oauth.yandex.ru](https://oauth.yandex.ru) с доступом «Получение статистики, чтение параметров своих и доверенных счётчиков».
2. Откройте в браузере:

   `https://oauth.yandex.ru/authorize?response_type=token&client_id=ИД_ПРИЛОЖЕНИЯ`

3. Скопируйте `token` из адресной строки и вставьте в лист **Настройки**. Скрипт сохранит токен и заменит ячейку на «токен сохранён».

Не коммитьте токен, `.clasp.json` и другие секреты в git.

## Структура

```
apps-script/
  Code.gs          меню, боковая панель, сбор отчёта
  Metrika.gs       запросы к API Яндекс.Метрики
  Sheets.gs        листы «Настройки» и «Данные»
  Sidebar.html     кнопки «Собрать отчёт» и «Показать цели»
  appsscript.json  права скрипта
```
