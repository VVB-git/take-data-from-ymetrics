Типы слайдов из Figma

В файле «Отчеты у ВВБ» два формата. Для подстановки данных из Метрики / Excel используется портретный шаблон ~595×896 (кампании вроде «Уют мебель», Divano, Compressortyt). Широкие слайды 1920×1080 — сводные аналитические экраны с уникальными графиками; их в этот набор не выносил.

Повторяющиеся кадры в Figma сведены к 11 типам. Каждый тип — отдельная HTML-страница. Цифры берутся из report/data.js, вёрстку трогать не нужно.

  • 01. Титульный — название РК, сайт, отчётный период, цикл, дата отчёта. В Figma: «Титульник основа», «Главная».
  • 02. Медиаплан план/факт — показы, охват, частота, CTR, бюджет, клики. «Плановые показатели», «План/Факт».
  • 03. Поведение: результаты — время / отказы / глубина (метка vs без метки) + доли устройств. «Вторичка».
  • 04. Поведение по устройствам — отказы, глубина, время для ПК / смартфонов / планшетов.
  • 05. Возраст и пол (доли) — бары возраста и пончики пола.
  • 06. Статистика по возрасту — те же 3 метрики по возрастам и по полу. «Скрины».
  • 07. Audience matching — % matching и % новых пользователей. «Мэтчинг».
  • 08. Post-click конверсии — прямые / ассоциированные + CPL. «Конверсии».
  • 09. Post-view — таблица целей и количества. «Результаты по PV».
  • 10. Статистика по баннерам — CTR, клики, показы по креативам. «Баннеры стата».
  • 11. Контакты — телефон и почта. «Конец».

Собранный пример кампании: полный отчёт «Уют мебель» (титул + медиаплан + поведение + контакты, без matching/конверсий/баннеров).
